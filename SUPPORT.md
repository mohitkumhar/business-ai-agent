# Support

Use these channels when you need help with ProfitPilot:

1. Read `README.md` for setup, architecture, services, and common workflows.
2. Check `Guide_to_start_project.md` and the integration guides for Telegram
   and WhatsApp setup.
3. Search existing GitHub issues before opening a new one.
4. Open a bug report or feature request with clear steps, expected behavior,
   actual behavior, logs, and environment details.
5. For security concerns, follow `SECURITY.md` and avoid posting sensitive
   details publicly.

The project is maintained by volunteers, so response times can vary. Clear
reproduction steps and focused questions make it much easier to help.
