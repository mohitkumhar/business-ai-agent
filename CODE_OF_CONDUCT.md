# Code of Conduct

ProfitPilot is an open-source project for contributors with different
backgrounds and experience levels. We expect everyone to help keep the project
welcoming, respectful, and practical.

## Expected Behavior

- Be respectful and patient in issues, pull requests, reviews, and chats.
- Assume good intent, especially with new contributors.
- Give feedback about the work, not the person.
- Accept constructive criticism gracefully.
- Credit ideas, code, and documentation that come from others.
- Keep discussions relevant to the project.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or behavior.
- Sexualized language or unwanted attention.
- Publishing private information without permission.
- Trolling, sustained disruption, or bad-faith participation.
- Sharing exploit details publicly instead of following `SECURITY.md`.

## Reporting

Report code of conduct concerns to the maintainers through GitHub. If a report
contains sensitive personal or security information, contact the maintainers
privately where possible and avoid posting unnecessary details in public.

Maintainers will review reports as promptly as possible and may ask for more
context before taking action.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block
participants who do not follow this code of conduct. Enforcement decisions are
made to protect the health of the project and its contributors.
